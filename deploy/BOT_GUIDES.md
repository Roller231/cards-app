# Инструкции в стартовом сообщении бота

При `/start` сохраняются прежнее приветствие, его изображение и кнопки-ссылки,
включая «Открыть ProntoPay». Ни один ролик автоматически не отправляется.
Следом в клавиатуре появляются включённые инструкции в выбранном порядке.
Нажатие `guide:<id>` отправляет только соответствующий ролик и его текст.

Админка: **Бот → Приветствие → Кнопки-инструкции**. Можно изменить название
и текст (HTML), загрузить/заменить MP4, убрать видео и оставить текст,
переставить, выключить, удалить или добавить инструкцию. Изменения списка
применяются кнопкой «Сохранить настройки» и видны в новых сообщениях `/start`.
Удалённые и выключенные инструкции недоступны и по старым кнопкам.
Существующий редактор кнопок-ссылок работает независимо.

Список хранится в `admin_settings.BOT_GUIDES`. При отсутствии записи
используются три исходные инструкции; сохранённый пустой список остаётся
пустым. Старый клиент админки, не передающий поле `guides`, список не меняет.
Видео хранятся в постоянном томе `backend_uploads`, каталог
`/app/static/uploads/bot_guides`. Исходные видео не добавляются в Git.

Первоначальное соответствие файлов пользователя:

| Кнопка | Исходный файл | Файл в томе |
| --- | --- | --- |
| Как оплатить юани | 137_ProntoPay_v03.mp4 | bot_guides/yuan.mp4 |
| Как оплатить сервис | 137_ProntoPay_v01_final.mp4 | bot_guides/services.mp4 |
| Как выпустить карту | 137_ProntoPay_v02_final.mp4 | bot_guides/card.mp4 |

Для начального наполнения подготовлены MP4 H.264/AAC с `faststart`,
разрешение 1080×1080 сохранено. Видео загружаются отдельно от образа в том.
При первом запросе Telegram получает файл, затем используется кеш `file_id`.
Видео отправляется фоновой задачей с отдельной сессией БД, чтобы загрузка
не задерживала `/start` и кнопки менеджеров. Повторный клик того же чата
до завершения отправки не запускает вторую загрузку.

`POST /admin/bot/guides/upload-video` доступен только администратору,
принимает MP4 до 50 МБ и назначает случайное безопасное имя.
Для этого маршрута выставлен отдельный лимит Nginx 51 МБ.
Остальные маршруты сохраняют прежние ограничения.

Проверки: backend unittest, сборка frontend, ESLint нового редактора,
`nginx -t`, контрольные суммы размещённых видео. В автоматических тестах
все обращения к Telegram заменяются mock; реальные сообщения не рассылаются.
